# Профили

В профилях хранятся списки, оценки и уникальные для варианта профиля функции, например дата создания аккаунта (на Shikimori). История просмотра описана в разделе [Плеер](player.md#история).

## Локальный

Все списки хранятся в JSON файлах локально.

Поддерживает списки:
- [История](player.md#история)
- Избранное
- Запланировано
- Пересматриваю
- Просмотрено
- Отложено
- Брошено

## Shikimori

Все списки имеют локальную копию в JSON, а также синхронизируются со списками в аккаунте Shikimori.

Поддерживает списки:
- [История](player.md#история) (локально)
- Смотрю (синхронизируется с [историей](player.md#история))
- Запланировано
- Пересматриваю
- Просмотрено
- Отложено
- Брошено

Возможность оценивания аниме ([страница аниме](ui.md#страница-аниме)).
