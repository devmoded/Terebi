# Кэширование

Сохраняются:
- Подробная информации об аниме из Shikimori. 
- Информация об аниме из Kodik - переводы, сезоны, эпизоды (с их ссылками на плеер)
- Обложки списков. Они хранятся по имени списка, поэтому при его обновлении новая обложка просто заменит старую. Подробнее о карточках — в разделе [Списки](ui.md#списки).

В настройках имеется раздел для управления хранилищем, там можно очистить весь кэш.

Какие данные относятся к профилю, описано в разделе [Профили](profiles.md).
