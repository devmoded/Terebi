# Управление с пультом

Навигация построена на фокусе: стрелки перемещают фокус, Enter/OK активирует выбранный элемент ([Интерфейс](ui.md)). В плеере, когда элементы управления скрыты, стрелки управляют воспроизведением ([Плеер](player.md)).

| Действие | Клавиша / кнопка пульта | Где работает |
|---|---|---|
| Перемещение фокуса | Стрелки | Интерфейс |
| Активировать выбранный элемент | Enter / OK | Интерфейс |
| Назад / закрыть попап | Escape / Back | Интерфейс |
| Пауза / продолжить | Space, Play/Pause, Enter / OK | Плеер |
| Перемотка назад / вперёд | ← / → | Плеер, когда элементы управления скрыты |
| Громкость | ↑ / ↓ | Плеер, когда элементы управления скрыты |
| Следующий / предыдущий эпизод | Media Next / Media Previous | Плеер |
| Полноэкранный режим | F | Плеер |
| Скриншот | S | Плеер |
| Загрузить текущий эпизод | D | Плеер |
| Закрыть плеер | Escape / Back | Плеер |
