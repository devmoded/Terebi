# Разделы программы и функционал

Расположение элементов заголовка:
- Левый угол:
  - Круглая кнопка с аватаром текущего профиля. При нажатии отрывает попап с выбором доступного профиля, после профилей идёт кнопка для создания нового профиля "Добавить профиль". Подробнее — в разделе [Профили](profiles.md).

- Центр:
  - Раздел "Главная"
  - Раздел "Списки"
  - Раздел "Загрузки"

- Правый угол:
  - Кнопка настроек.
  - Кнопка закрытия программы.

Управление с пульта описано в разделе [Управление с пультом](remote.md), воспроизведение — в разделе [Плеер](player.md).

## Главная

На главной странице находятся разделы "Последнее просмотренное" и "Популярное". В них находятся карточки аналогичные тем, что описаны в следующем разделе "Списки".

При нажатии на карточку открывается страница выбранного аниме.

Для "Последнего просмотренного" аниме берутся из локального списка "История". Если он пуст, то вместо карточек будет надпись "Ещё ничего не просмотрено".

Для "Популярного" аниме берутся из Shikimori.

В каждом разделе карточки расположены в прокручиваемом контейнере. Всего могут быть показаны 10 карточек. При прокручивании до конца будет специальная кнопка по размеру с карточку, которая открывает полный список - для "Последнего просмотренного" это список "История", для "Популярного" просто больше карточек с аниме запрашиваются у Shikimori.

Запросы для "Популярного" не кэшируются (см. раздел [Кэширование](caching.md)).

В настройках в разделе "Главная" можно поменять местами эти разделы, или отключить какие-то из них, или вообще все. Если были выключены все разделы, то на главной странице будет написано какое-то сообщение, либо помощь, либо пасхалка. Сообщение будет рандомно выбираться из файла с ними.

## Списки

На странице списков находятся представляющие их карточки. Карточки расположены в сетке.

**Внешний вид карточки:**
- *Соотношение сторон:* 3:4
- *Фон карточки:* Специальный цвет для фона из палитры Adwaita. Поверх обычного фона располагается изображение (описано ниже).
- *Изображение на фоне:* Последнее сохранённое аниме в списке, если список пуст, то ничего не накладывается. Изображение поверх фона накладывается так, чтобы полностью закрыть собой фон, то есть по ширине или высоте, в зависимости от более короткой стороны. Обложка берётся из поля `Poster` в информации об аниме.
- *Название списка:* Подпись расположена примерно на 5/6 (высоты) от верха карточки (или же 1/6 (высоты) от её низа). Сзади текста находится градиент от низа карточки до середины. Цвет градиента контрастный для текста. Если название не умещается, то оно прокручивается, а не просто обрезается.
- *Отступы от краёв (внутри):* Примерно 1/6 ширины.

Списки принадлежат профилю, подробнее — в разделе [Профили](profiles.md).

## Загрузки

На странице загрузок показаны загружающиеся в данный момент эпизоды, если их нет, то будет написано "Ничего не загружается".

По умолчанию эпизоды загружаются в `XDG_VIDEOS_DIR/Terebi/Animes/<название аниме>/<название сезона>/`. Название файла состоит из только номера эпизода, так как остальная информация уже есть в пути.

Переопределить шаблон для имени файла и место его сохранения можно в настройках, в разделе "Загрузки". Также там можно указать максимальное количество одновременных загрузок, по умолчанию: 5.

# Первоначальная настройка

При первом входе пользователю сначала будет предложено добавить профиль - будет показан выбор между доступными вариантами (см. раздел [Профили](profiles.md)). После этого, на следующем экране, необходимо будет указать API токен для Kodik (необходим для `hksm-app/kodik-api`, см. раздел [Реализация](development.md)).
