# Terebi

Terebi (яп. テレビ) - программа для просмотра аниме из базы Kodik (в перспективе и других источников). 

Интерфейс в ориентирован на удобное управление с помощью пульта, то есть под использование, например, с телевизора. Помимо просмотра также поддерживается загрузка эпизодов (а также просмотр загруженных). 

Имеет систему профилей: локальный, Shikimori (в будущем могут появится другие). Профили полезны, например, для ведения списков. Но их поддержка и варианты зависят от варианта профиля.

Для интерфейса используется GTK4 + Libadwaita.

# Ключевые возможности

- Просмотр аниме из Kodik, в перспективе — из других источников.
- Управление с пульта: навигация по фокусу и отдельные клавиши для плеера.
- Профили: локальный и Shikimori, списки и оценки.
- Загрузка эпизодов с возможностью продолжить прерванную загрузку.
- Просмотр скачанных эпизодов.
- История просмотра с сохранением позиции и времени.
- Кэширование метаданных и обложек.

# Технологии

Приложение написано на Go. Интерфейс — GTK4 + Libadwaita, воспроизведение — libmpv, загрузка — yt-dlp, данные об аниме — Shikimori и Kodik. Подробнее о библиотеках — в разделе [Реализация](development.md).
