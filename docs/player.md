# Плеер

Управление с пульта описано в разделе [Управление с пультом](remote.md).

Элементы интерфейса при нажатии паузе или ведении мышью:
- Таймлайн внизу.
- Текущее время просмотра слева от таймлайна.
- Время окончания эпизода справа от таймлайна.
- В центре экрана "Эпизод N". Название аниме и сезон ниже номера эпизода и меньше по размеру. Если они не помещаются, то текст прокручивается. Ограничение по ширине для названия аниме - примерно половина экрана. Выглядит как "Сезон: <Сезон>. <Название аниме>"
- Экран затемнён.
- В заголовке:
  - Левый угол:
    - Кнопка создания скриншота.
    - Кнопка загрузки эпизода.
  
  - Центр:
  
  - Правый угол:
    - Кнопка закрытия плеера.

При закрытии плеера текущая позиция просмотра сохраняется в истории. Помимо времени просмотра сохраняется время выхода, например чтобы в истории писать когда был просмотрен последний эпизод.

По умолчанию скриншот сохраняется в папку `XDG_PICTURES_DIR/Terebi/Screenshots<название аниме>/<название сезона>/`. В названии файла время просмотра (когда сделан скриншот) и номер эпизода, остальное есть в пути к файлу.

Переопределить шаблон для имени скриншота и место сохранения можно в настройках, в разделе "Плеер".

## История

История — один из списков профиля, подробнее — в разделе [Профили](profiles.md).

В истории хранятся два типа эпизодов - недосмотренные и просмотренные.

Для недосмотренных сохраняются позиция просмотра, время закрытия плеера и другая информация.

В просмотренных эпизодах просто хранится список из просмотренных, чтобы уменьшить потребляемое место на диске.
