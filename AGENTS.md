## Архитектурные инварианты

- `gui` импортирует только `internal/api` и не импортирует `internal/backend`.
- `backend` импортирует `internal/api` и не импортирует GTK (`gotk4`, `gotk4-adwaita`).
- `internal/api` не импортирует GUI, backend и внешние клиенты.
- `cmd/terebi` — единственное место, где создаются конкретные backend и GUI.
- Запросы и команды идут через интерфейсы `api`, асинхронные события — через подписку на `api.Event`.
- Backend работает в горутинах; GUI доставляет события в GTK main loop через `glib.IdleAdd`.
- Плеер — исключение: backend владеет mpv, GUI передаёт ему нативный handle окна.

Подробнее — в [структуре проекта](docs/structure.md).

## Команды

```bash
gofmt -w .
go vet ./...
go test ./...
CGO_ENABLED=1 go build ./...
```

Сборка требует CGO и установленных системных библиотек.

## Окружение

- Go 1.27+.
- GTK4 и libadwaita (заголовочные файлы и `pkg-config`).
- libmpv.
- `yt-dlp`.
- `ffmpeg` — для HLS/m3u8 и обработки видео.
- CLI `kodik` из `BatogiX/kodik` — для резолвинга ссылок.

## Код

- Форматирование — `gofmt`; код должен проходить `go vet`.
- Сетевые и файловые операции принимают `context.Context`.
- Ошибки оборачиваются с контекстом, без паник в обычном потоке.
- Зависимости передаются через конструкторы, глобальное состояние не добавляется.
- Идентификаторы пакетов и файлов — на английском, документация — на русском.
- Комментарии — только там, где объясняют причину, а не пересказывают код.

## Тесты

- `go test ./...` должен проходить.
- Внешние Kodik и Shikimori в юнит-тестах мокаются; сетевые запросы в тестах не выполняются.
- Логику, не зависящую от GTK, выносить в backend и покрывать тестами.
- Для тестовых данных использовать `testdata`.

## Git

- Сообщения коммитов — на английском.
- Коммитить только файлы, относящиеся к задаче; не захватывать случайные untracked-файлы.
- Не выполнять `git push` без явного указания.
- Не переписывать историю и не делать force-push без явного указания.

## Границы задач

- Не реализовывать функции вне текущего этапа из [roadmap](docs/roadmap.md) без явной просьбы.
- Пустые каталоги Git не отслеживает; не добавлять `.gitkeep` без необходимости.
- Не дублировать содержимое `docs` в этом файле — лучше обновить ссылку или соответствующий документ.
